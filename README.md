# Decision record template

A Markdown template for recording a decision, its rationale, approval evidence and the work it affects. It works for a vendor renewal, an architecture choice or a policy change.

Start with the [blank template](decision-record-template.md), or read the [filled vendor-renewal example](examples/vendor-renewal.md). The example is fictional and follows Traceway's public decision-log guide.

## Use it

1. Copy `decision-record-template.md` into your own records folder and give it a stable ID and filename.
2. State the choice, why it is needed and which alternatives were rejected.
3. Name the required approver or approvers and the approval rule. Keep the status **Draft** until the required approval is evidenced.
4. Link the goal, affected records and follow-up work. Record who will review the effect on each item.
5. When the decision changes, retain the earlier record and approval evidence. Link the proposed replacement; mark the earlier record superseded only when the replacement takes effect under your process.

Typing **Approved** does not establish approval. This is an editable manual record: it does not enforce permissions, preserve an immutable history or update a work tracker. Use real evidence references in your own records; the example contains none.
